A structured, phased body of applied ML work. Covers data preparation, feature engineering, model evaluation, model tuning, model persistance, and deployment. Still a work in progress and each phase builds upon the last.

**Highlights:**
- **ML API using FastAPI** - Trained, hypertuned, wrapped in pipeline, and saved model. Used FastAPI to create an app that uses this model (bank loan risk prediction and score). Live link: https://ai-ml-apprenticeship.onrender.com/docs
- **Bike Rental Demand Analysis** — EDA and feature engineering on time-series rental data to identify usage patterns and demand drivers
- **Home Loan Default Prediction** — Classification pipeline with encoding strategies, class imbalance handling, and model evaluation
- **NLP Sentiment Analysis** — Text classification using VADER and transformer-based approaches, with class imbalance work
- **FAQ Embedding Chatbot** — Retrieval-based chatbot using embeddings and similarity search
